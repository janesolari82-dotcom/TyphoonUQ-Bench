# Licenses and attribution

TyphoonUQ-Bench is a *derived* dataset and codebase that builds on three
upstream archives, each with its own license. The benchmark code and the
derived manifest are released under MIT, but downstream users must respect
the upstream terms whenever they redistribute raw or near-raw assets.

## 2. Upstream archives

### 2.1 Digital Typhoon (NII / DIAS)

- Citation: Kitamoto A, Hwang J, Vuillod B, Gautier L, Tian Y, Clanuwat T.
  *Digital Typhoon: Long-term Satellite Image Dataset for the
  Spatio-Temporal Modeling of Tropical Cyclones.* NeurIPS 2023.
- DOI: <https://doi.org/10.20783/DIAS.664>
- License: CC-BY-4.0 (DIAS distribution terms).
- Requirement when redistributing: cite the dataset DOI **and** the
  NeurIPS 2023 paper.

### 2.2 JMA RSMC best-track

- Citation: Japan Meteorological Agency, RSMC Tokyo - Typhoon Center.
  *RSMC Best Track Data (Text).*
- URL: <https://www.jma.go.jp/jma/jma-eng/jma-center/rsmc-hp-pub-eg/besttrack.html>
- License: Japan Public Data License 1.0 / CC-BY-4.0-compatible (editorial use; commercial use permitted with attribution).
- Requirement when redistributing: include a JMA / RSMC Tokyo attribution line and document any editorial reformatting.

### 2.3 IBTrACS v04r01

- Citation: Knapp KR, Kruk MC, Levinson DH, Diamond HJ, Neumann CJ.
  *The International Best Track Archive for Climate Stewardship
  (IBTrACS): Unifying Tropical Cyclone Data.* Bull. Amer. Meteor. Soc.,

## 4. What you should NOT redistribute through this repository

- The Digital Typhoon imagery itself. Users must download it from DIAS.
- Raw IBTrACS or JMA text files. The repository only ships derived
  parquets; raw files belong to the upstream archives.
- Operational forecast products (e.g. JMA's real-time RSMC bulletins) that
  fall outside the CC-BY-4.0 best-track release.

---

## 5. Data-protection note

TyphoonUQ-Bench does not contain any personal data. All records are
publicly observed geophysical quantities (storm centres, intensity
estimates) released by national meteorological agencies for research use.
